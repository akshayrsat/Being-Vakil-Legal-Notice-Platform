# Notice Desk ODR document templates: placeholder reference

Templates: `Arbitral_Award_Template.docx` and `Settlement_Agreement_Template.docx` (same folder). Generated by `/workspace/odr/build/*.py`.

## Template conventions for the fill engine

- `{{snake_case}}` is a value placeholder. Each placeholder sits whole inside a single Word run (it is never split), so a plain string replace on each `w:t` works.
- `[[IF flag]] … [[ELSE]] … [[END]]` is a conditional block. Every marker sits in its **own paragraph** (style *Template Directive*, blue 8.5 pt). Keep the paragraphs in the chosen branch and delete the marker paragraphs and the other branch. Blocks can nest (in the settlement agreement, `award_on_agreed_terms` sits inside `arbitration_pending`), so match them stack-wise. In table cells (the award's Appearances table and the mediator box), the markers are paragraphs inside the cell.
- `[[REPEAT name]] … [[END_REPEAT]]` is a repeatable paragraph block (co-obligor party description). Clone the enclosed paragraphs once per item, and output nothing if the list is empty.
- `[[ROW name]]` is a shaded marker row in a table. Delete the marker row and clone the **row immediately below** it once per item. If there are no items, delete both rows.
- Paragraph and clause numbers are real Word auto-numbering, so they renumber themselves once blocks are removed. Fixed cross-references only point to clauses that never get removed.
- Amounts are printed as `Rs. {{x}}/-`. Pass Indian digit grouping (e.g. 1,23,456.00) and words in the Indian system ("One Lakh Twenty-Three Thousand ...").
- Sources: **Excel upload** (bank sheet), **Case record** (ODR case/arbitrator/bank master data and uploaded documents), **Hearing log** (notices, Meet attendance, orders), **Staff entry at award time** / **Staff entry at settlement**, **Arbitrator entry** (findings and reasons, which must come from the arbitrator), **Mediator entry**, **System (computed)**.
