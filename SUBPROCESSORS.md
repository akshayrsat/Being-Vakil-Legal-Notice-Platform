# Sub-processors

**Draft for counsel review.** This list is a technical note for the product. It is not legal advice and it is not a signed agreement.

Being Vakil Associates uses the following sub-processors when a notice or an ODR proceeding needs them. The bank remains the organisation that decides the purpose of the customer data for that work.

| Sub-processor | What it is used for |
| --- | --- |
| MSG91 | SMS, email, and WhatsApp delivery of notices and hearing messages |
| Meta WhatsApp | WhatsApp delivery through the messaging path |
| Google Meet and Google Calendar | Hearing links and calendar invites |
| India Post | Speed Post booking records entered by staff |
| Google Cloud India | Hosting of the application and the database (Cloud Run and Cloud SQL) |

Personal data sent to a sub-processor is limited to what that step needs: a mobile number or email for a message, a name and time for a hearing, or the stored files for the application itself.
